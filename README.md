# 실증적AI개발프로젝트Ⅱ · 1주차 수업자료

동아대학교 AI학과 `실증적AI개발프로젝트Ⅱ(종합설계)` 1주차 수업용 웹 슬라이드입니다.

## 가장 쉬운 실행 방법

1. 파일 탐색기 주소창에 `D:\Github\AIProject_2026_2`를 붙여 넣고 Enter를 누릅니다.
2. 폴더 안의 `수업자료_열기.cmd`를 더블클릭합니다.
3. 잠시 후 브라우저에서 `http://localhost:3000`이 열립니다.
4. 실행 중 나타난 검은 창을 닫으면 로컬 사이트도 종료됩니다.

## index.html이 없는 이유

이 자료는 단일 HTML 파일이 아니라 React와 Vinext로 만든 웹사이트입니다. 따라서 `index.html`을 직접 여는 대신 로컬 개발 서버를 실행한 뒤 브라우저에서 접속해야 합니다.

슬라이드 내용은 `app/page.tsx`, 디자인은 `app/globals.css`, 사례 이미지는 `public/cases` 폴더에 있습니다.

## 발표할 때

- 브라우저 화면 위쪽의 `슬라이드쇼 화면` 버튼으로 청중용 화면을 엽니다.
- `발표자 화면` 버튼으로 현재 슬라이드, 다음 슬라이드와 발표 메모를 확인합니다.
- 두 화면의 페이지 이동은 서로 동기화됩니다.
